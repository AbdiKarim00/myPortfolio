## Getting Started

To view this portfolio locally or contribute to its development, follow the instructions below.

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Git installed on your local machine
- A code editor (VS Code, Sublime Text, etc.)

## Installation

1. Clone the repository to your local machine:

```bash
git clone https://github.com/AbdiKarim00/myPortfolio.git
```

2. Navigate to the project directory:

```bash
cd myPortfolio
```

3. Open the project in your preferred code editor:

```bash
code .
```

## Usage

To view the portfolio:

1. Open the `index.html` file in your web browser, or
2. Use a local development server:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (if you have http-server installed)
npx http-server
```

3. Navigate to `http://localhost:8000` in your browser
